Features
Scoring: text i Scores each segment’s transcript with your OpenAI model and prompt (e.g. funniness). Uses API tokens per segment. Turning this off removes text from the fused score unless you enable other signals.
Scoring: audio i Runs local librosa-style energy analysis on the segment’s audio. No extra API cost. If disabled, audio does not contribute to the blended score.
Scoring: visual (costs $) i Sends sampled frames to a vision model for scoring. Costs money, adds latency, and needs API access. Use when you want visuals to influence ranking; leave off to save budget.
Scene detection i Uses PySceneDetect to find cuts and nudge Whisper segments toward scene boundaries. Slightly more CPU time; can produce cleaner edits. If off, segments follow transcript timing only.
Vertical export i After ranking, exports top clips as 9:16 vertical MP4s with subtitles into data/outputs/. Extra ffmpeg work and disk space. Ranked files in candidates_ranked still exist either way.
YouTube trending i Prepends trending videos from the YouTube Data API to the download pool (requires API key setup). Does not affect splice uploads or rank-only on files already local.
